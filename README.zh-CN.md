# science_hu 科研绘图技能

[English](README.md)

两个可独立安装的 Skill，分别用于设计科研图和把现成图片转成 SVG 与可编辑 PowerPoint。

| Skill | 适用任务 | 安装包 |
| --- | --- | --- |
| `science-hu-figure-design` | 从科研主线整理生图提示词，确认草图后导出。 | [下载 ZIP](science-hu-figure-design.zip) |
| `science-hu-vectorize` | 把现成图片或兼容的 SVG 转成可编辑的矢量图。 | [下载 ZIP](science-hu-vectorize.zip) |

支持上传 Skill 的工作台可以直接导入对应 ZIP。Codex 可将包内目录解压到 `~/.agents/skills/`，Claude Code 可解压到 `~/.claude/skills/`。具体用法和依赖见各自的说明。转换在当前执行环境中完成，需要 Python，无需 API 密钥，首次运行可能下载依赖。
