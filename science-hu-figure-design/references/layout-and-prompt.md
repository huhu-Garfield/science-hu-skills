# 主线、参考图与提示词

## 提炼主线

- 用“研究对象 → 核心发现或比较 → 可观察结果”记录主张。另记一项最值得凸显的亮点，例如跨阶段差异、关键反馈环或两条件结果分化。
- 把内容化为短标签和有向关系。为每条关系记下来源、目标、关系类型和证据。实验组、物种、组织、时间点、单位及统计信息由用户材料决定。
- 规划视觉中心、背景信息和图例。重复图标在全图使用同一含义。只在图面需要时标注完整术语、比例尺或颜色含义。

## 布局选择

| 版式 | 适用情形 | 构图 |
| --- | --- | --- |
| 上下 | 研究对象到机制再到表型，或全景与细节串联 | 上层给背景或输入，中层展开机制，下层放结果。顺序明确时用纵向对齐的箭头。 |
| 左右 | 对照与处理、两种状态、时间顺序或同一机制分支 | 同层级节点对齐，两边按同一尺度和颜色编码绘制。 |
| 综述圆圈 | 多阶段过程、中心主题与多个生态位或循环关系 | 中心给共同主题，外围模块沿阅读顺序排列。存在闭环证据时才将最后一段接回起点。 |

分析参考图时，把每张图的阅读方向、模块边界、留白、主焦点和图例位置记为结构描述。按照当前文章的主张重新安排模块和图标。仅借鉴构图时，使用自绘符号和用户提供的内容。

## 可直接交给出图模型的提示词

```text
任务：制作一张科研机制示意图 / 图文摘要 / 综述图。
图的一句话主张：[用户已经提供或确认的发现]。
优先强调：[最值得一眼看到的差异、步骤或关系]。

画布和阅读顺序：[比例、上下 / 左右 / 综述圆圈以及阅读方向]。
分区：[逐区写坐标方位、独立标签、应出现的对象及其层级]。
关系：[来源 → 目标、激活 / 抑制 / 相关 / 迁移，以及线型如何区分]。
标签：[逐字列出，注明中文或英文，并保留上下标、希腊字母和符号]。
配色与图例：[每种颜色的含义，保持相同实体颜色一致]。

视觉要求：轮廓清晰，扁平色块优先，少量配色，留足标签和箭头空间。
保持同一线宽和箭头语义，参考图只用于指定的布局规律。
图面只使用列出的标签和关系。无证据的节点和箭头留空。
输出一张可供确认构图的草图，使用完整画布，保持所有模块可见。
```

标签密集时，可以让出图模型留出文字位置，再在矢量版补充经确认的标签清单。模型试图生成新细节时，用原文核对后再采纳。
